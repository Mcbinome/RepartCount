# RepartCount

Application web pour répartir les frais en groupe (style Tricount), avec **parts personnalisables** par personne.

## Fonctionnalités

- Créer des groupes / voyages
- Ajouter des participants avec un nombre de **parts** (ex. adulte = 1, enfant = 0,5)
- Enregistrer des dépenses (qui a payé, qui est concerné)
- Ajuster les parts **par dépense** si besoin
- Voir les soldes et les remboursements optimisés
- Données sauvegardées dans le navigateur (`localStorage`)

## Démarrer

```bash
npm install
npm run dev
```

Puis ouvrir l’URL affichée (souvent `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```
